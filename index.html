THE TOOLKIT

Three tools. One smooth workflow.

Understand the role of each tool before deploying your first website.

G
VERSION CONTROL

Git

Git tracks changes in your project and helps you manage different versions of your code.

Think: Code History
GH
ONLINE REPOSITORY

GitHub

GitHub stores your Git repositories online so your project can be shared, backed up and connected to deployment.

Think: Online Project Home
N
DEPLOYMENT

Netlify

Netlify publishes your website to the internet and provides a public URL.

Think: Make It Live

QUICK REFERENCE

Git commands you should know

Remember: ADD → COMMIT → PUSH

01
git add .

Prepare Changes

Adds changed files to the staging area.

02
git commit -m "updated website"

Save a Version

Saves prepared changes with a message.

03
git push

Upload to GitHub

Sends committed changes to GitHub.
