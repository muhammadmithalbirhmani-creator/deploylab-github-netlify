FOUNDATION

Understand the Main Concepts

Before deploying a website, it is important to understand the role of Git, GitHub and Netlify.

Git

Git

Git is a version control system used to track changes in your project files.

Example: Save different versions of your website.
GH

GitHub

GitHub is an online platform where Git repositories can be stored, managed and shared.

Example: Store your website code online.
N

Netlify

Netlify is a hosting and deployment platform that publishes your website on the internet.

Example: Turn your GitHub project into a live website.

STEP BY STEP

How to Deploy a Website

Follow these simple steps to publish your website.

01

Create Your Website

First create your website using HTML, CSS and JavaScript. Make sure your main file is named index.html.

Important: Keep index.html in the root folder of your project.
02

Initialize Git

Open the project folder in VS Code or Command Prompt and initialize Git.

git init
03

Track Your Files

Add all project files to the Git staging area.

git add .
04

Create a Commit

Save a snapshot of your current project with a meaningful commit message.

git commit -m "Initial website"
05

Push to GitHub

Connect your local project with your GitHub repository and push your files.

git push
06

Connect GitHub with Netlify

Open Netlify, choose GitHub from Import an existing project, and select your repository.

Netlify can automatically redeploy your website whenever you push new changes to GitHub.
07

Configure Deployment

For a simple HTML/CSS/JavaScript website, use these settings:

Base directory Blank
Build command Blank
Publish directory .
Functions directory Blank
08

Deploy Your Website

Click Deploy project. Netlify will build and publish your website.

✓ Your website is now live on the internet.

QUICK REFERENCE

Essential Git Commands

These are the basic commands used during deployment.

git init Initialize Git
git status Check project status
git add . Stage all files
git commit -m "message" Save changes
git push Upload changes to GitHub
git pull Download latest changes
!

IMPORTANT

Keep index.html in the Root Folder

Netlify needs to find your main webpage. For a basic static website, keep index.html in the root directory.

📁 deploylab-github-netlify ├── index.html ├── styles.css └── app.js
